# shelibenm.github.io
This is a project done in 2022 showcasing student work as part of a short course on learning Python and art. Some of the platforms we used are no longer supported [like Trinket] or have changed [Replit] so I made some adjustments just to keep the ideas alive.
1. Using the pyp5js module - https://berinhard.github.io/pyp5js
2. Creating shortcuts for script alternatives
3. Pending - Creating an index file to showcase software and alternatives to Processing script creation software [Frey project MIT]
4. Adding folders to the repository- for each student work there is a dedicated folder enumrated as "Fal_#"
